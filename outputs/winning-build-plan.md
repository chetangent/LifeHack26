# Winning Build Plan

## Objective

Build the smallest possible MVP that feels like a real product, demonstrates clear AI value, and produces measurable before-and-after outcomes for judges.

## Winning product angle

Do not position this as a generic AI content generator.

Position it as:

**A recommendation-readiness platform for AI commerce.**

The winning promise is:

- tell brands whether AI can recommend their product
- explain why not
- generate the missing content
- prove the improvement through simulation

## Must-have features

These are the features most likely to matter for the demo:

1. Upload or load a small catalog
2. Select one product
3. Show raw content
4. Generate enriched AI-ready content
5. Show readiness score and missing fields
6. Run simulation prompts
7. Show improved score and selection confidence after enrichment

## Nice-to-have features

Only build these if the core flow is already strong:

- export enriched JSON
- multiple categories
- team workspace
- advanced analytics
- live CMS integration

## Ideal judge moment

The strongest moment in the demo is:

"This product was not recommendable. We enriched it, filled the missing reasoning signals, and now it wins the prompt simulation."

If that moment is clear, the rest of the product becomes believable.

## Recommended build order

### Phase 1
- homepage and positioning
- sample dataset
- catalog table
- base score display

### Phase 2
- product detail screen
- raw vs enriched comparison
- gap detection

### Phase 3
- simulation prompt engine
- before/after confidence comparison

### Phase 4
- CSV upload
- export flow
- README polish

## Suggested UX

Keep the app simple and narrative-driven:

- landing page
- dashboard
- product detail panel
- simulation results

Avoid overbuilding admin features. The app should feel demoable in under four clicks.

## Suggested scoring dimensions

- Completeness
- Context
- Persona fit
- Use-case fit
- Tradeoff clarity
- Trust signals
- Machine readability

## Suggested demo KPI

Use two numbers throughout the story:

- AI readiness score
- prompt simulation win rate

Example:

- Score: 52 -> 81
- Win rate: 33% -> 100%

## Suggested sample prompt set

- "I need lightweight running shoes for humid weather under S$200."
- "I'm training for my first half marathon and need breathable daily trainers."
- "What's the best value neutral shoe for hot climates?"

## What to avoid

- too many categories
- generic chat UI with no measurable output
- claims that feel hand-wavy or unverifiable
- a demo that is only content generation
- too much time spent on setup during the video

## Team execution checklist

- define one hero SKU
- define one weak baseline and one improved version
- finalize score logic
- finalize three simulation prompts
- polish visuals
- script the video
- rehearse the demo twice

## Best final pitch line

"As shopping shifts from browsing pages to asking AI, brands need content that is not just searchable, but recommendable."
